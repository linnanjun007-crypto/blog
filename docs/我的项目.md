## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 项目名 |
| 年份 | 是 | 数字，如 2026 |
| 介绍 | 是 | 一句话 / 一段介绍 |
| 图片 | 否 | 图片网址，或本地路径（本地图片请把文件发我） |
| 链接 | 否 | 项目官网 / 演示地址；**没有独立网站就留空** |
| GitHub | 否 | GitHub 仓库链接；**只有 GitHub 时填这里、「链接」留空** |
| NPM | 否 | NPM 包链接 |
| 标签 | 否 | 逗号分隔，如 `RAG, FastAPI` |
